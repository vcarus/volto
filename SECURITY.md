# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/vcarus/volto/security/advisories/new). Do not open a public issue for anything exploitable.

Please include the volto version (or commit), a minimal reproduction, and the impact you believe it has. Reports are acknowledged and fixed on a best-effort basis.

## Supported versions

Only the latest release receives fixes.
